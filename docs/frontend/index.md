# HTML, CSS & JavaScript

Build the **KSR Store** website from a blank file to a responsive, accessible shop that loads products from an API and has a working cart. Shared by the Python and Java tracks: the same frontend later talks to your Django REST Framework or Spring Boot backend.

!!! abstract "By the end of this module, you can"
    - Write semantic, accessible HTML pages and forms that send data to a backend
    - Style them with modern CSS: the box model, Flexbox, Grid, responsive design, variables and dark mode
    - Program in JavaScript: variables, functions, arrays, objects, the DOM, events and async code
    - Build interactive features (live search, filters, a persistent cart, validated checkout) on top of a REST API

!!! tip "Every screenshot and output is real"
    The 20 lessons were replayed in order, in one `ksr-store` folder. Every page screenshot was taken in Chrome, every console and Node output comes from running the code, and the API lessons ran against the real mock server from lesson 10. Start by downloading the [KSR Store images](../assets/frontend/ksr-store/ksr-store-images.zip).
