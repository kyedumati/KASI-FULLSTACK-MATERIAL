# How to Use This Material

1. **Pick your track:** [Full Stack Java](../roadmaps/java-track.md) or [Full Stack Python](../roadmaps/python-track.md).
2. **Follow the order.** Each topic builds on the previous one.
3. **Type the code yourself.** Don't just copy. Typing builds muscle memory.
4. **Do the exercises before looking at solutions.** Solutions are hidden in collapsible blocks.
5. **Revise with the cheat sheet** at the end of every lesson.
