# Lesson Template

Every lesson page follows this structure. Trainers: copy it when you write a new topic.

```markdown
# <Topic Name>

!!! abstract "Learning Objectives"
    By the end of this lesson, you can:

    - ...

## Prerequisites
## The Problem
## Concept Explanation
## Key Terminology
## Step-by-Step Code Walkthrough
### Example 1: Simplest version
### Example 2: One more idea
### Example 3: Real-world version
## How It Works Behind the Scenes
## Common Mistakes & Errors
## Best Practices
## Hands-on Lab
## Practice Exercises
## Solutions        <!-- wrap each in ??? success "Solution" -->
## Mini Assignment
## Interview Questions
## Quick Revision Cheat Sheet
```

## Callout boxes to use

| Box | Syntax | Use for |
|-----|--------|---------|
| Common Mistake | `!!! mistake "Common Mistake"` | Beginner errors and fixes |
| In Real Projects | `!!! realworld "In Real Projects"` | Industry usage |
| Interview Question | `!!! interview "Interview Question"` | Interview Q&A |
| Tip | `!!! tip` | Shortcuts and good habits |
| Hidden solution | `??? success "Solution"` | Exercise answers |
