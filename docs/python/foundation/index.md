# Python Foundation

The building blocks of every Python program. No prior programming knowledge needed.

!!! abstract "By the end of this module, you can"
    - Install Python and run programs from VS Code and the terminal
    - Store data in variables and choose the right data type
    - Calculate and compare with operators, read input and format output
    - Make decisions with `if` and repeat work with loops
    - Work with strings, lists, tuples, sets and dictionaries
