# Functions & Modules

Organise your code into reusable pieces, use Python's huge library ecosystem, and set up projects the way professional teams do.

!!! abstract "By the end of this module, you can"
    - Write functions with parameters, defaults, `*args`, `**kwargs` and return values
    - Use `lambda`, `map`, `filter`, `sorted(key=...)` and comprehensions to process data
    - Split code into modules and packages and use the standard library
    - Create virtual environments and manage dependencies with `pip` and `requirements.txt`
